## About

integrations — for B2B SaaS and e-commerce clients across the US, UK and Europe.

I also build WooCommerce storefronts with custom checkout and product logic, and handle the

architecture.

## What I build

- **Custom Gutenberg blocks** — server-rendered via PHP templates, driven by ACF field groups
  rather than hand-written block registration
- **WordPress plugins** — including an in-house plugin that generates blocks from reusable ACF
  field groups, cutting block setup time across every client site
- **Custom REST API endpoints** — powering dynamic, client-editable content on decoupled and
  hybrid front ends
- **WooCommerce storefronts** — custom checkout flows, product configurators, payment and
  shipping extensions
- **Performance work** — Core Web Vitals, CLS and load-time reduction on high-traffic pages
- **Pre-launch QA, SEO audits and migrations** — WP Engine staging-to-production deployments
  and large content migrations
